# DevOps Git Flow

Учебный репозиторий для демонстрации стратегии ветвления Git Flow.

## Ветки

- `main` — стабильная версия, изменения только через Pull Request.
- `develop` — интеграционная ветка для подготовки релиза.
- `feature/*` — короткоживущие ветки для отдельных задач.

## CI/CD pipeline

### Push в `feature/*`
1. Установка зависимостей.
2. Линтинг и проверка форматирования.
3. Запуск unit-тестов.
4. Сборка проекта и публикация результатов проверки.

### Слияние в `develop`
1. Повторный lint/test/build.
2. Интеграционные тесты.
3. Деплой на staging.
4. Smoke-тесты staging.

### Слияние в `main`
1. Финальная проверка и создание версии/release.
2. Сборка production-артефакта.
3. Деплой в production.
4. Health-check и уведомление команды.
